NugNav is a live, evolving web application built to help adults in New York compare retailer-listed cannabis prices rather than rely on a single recommended product. Visitors can browse products and brands, search by ZIP code or location, filter by category and price, and review nearby retailer options.

The application distinguishes verified same-product comparisons from broader nearby listings, with transparent coverage information when menu prices are unavailable. NugNav is in beta and does not sell, deliver or process cannabis payments. The project demonstrates location-based search, data-driven interfaces and custom comparison workflows.
