# Calypso Digital Studio Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first working Astro foundation for Calypso Digital Studio with the approved Warm Creative Workshop design system, six stable routes, structured portfolio content, real source-derived imagery, and reproducible GitHub Actions validation.

**Architecture:** The site is a static Astro application with TypeScript, structured project content, reusable layout primitives, and minimal browser JavaScript. The first pull request establishes the visual and technical foundation only; complete case studies, the interactive intake wizard, live email delivery, and production-domain configuration remain separate later plans.

**Tech Stack:** Astro 7.0.9, TypeScript 5.9.3, `@astrojs/check` 0.9.9, Node 22.22.2, CSS custom properties, Astro content collections, GitHub Actions, Cloudflare Pages.

## Global Constraints

- Use Node `22.22.2` in GitHub Actions and `.nvmrc`.
- Pin `astro` to `7.0.9`, `@astrojs/check` to `0.9.9`, and `typescript` to `5.9.3`.
- Build static output only; no server adapter is added in this plan.
- Use Fraunces for display typography and Manrope for interface/body typography through a Google Fonts stylesheet link.
- Use the approved palette exactly: `#F7F1E7`, `#FFFDF8`, `#25231F`, `#B64F30`, `#62659A`, `#5D6C57`, `#E5B29E`, `#D8D6EA`.
- Customer-facing copy must use plain language, first person where Evan is the service provider, and no invented team, results, history, pricing, or client outcomes.
- Good Intentions must be labeled as in progress and must not imply live inventory or live checkout.
- Real portfolio captures must be used; generic stock imagery and fabricated interfaces are prohibited.
- The supplied square JPEG is a large-format master asset, not the small header mark or favicon.
- Mobile layouts must be intentionally designed and verified at `390px` and `430px`; desktop must be verified at `1440px`.
- No route may produce horizontal overflow.
- All interactive elements must have visible keyboard focus and WCAG AA color contrast.
- Respect `prefers-reduced-motion`.
- Secrets and live form credentials must not be committed.
- The guided intake route in this plan is an informational shell only; it must not pretend live form submission is active.
- Keep `Archive 9.zip` as a source archive, but do not serve it from `public/`.
- Run locked dependency installation, content validation, Astro checks, TypeScript checks, production build, asset verification, and build-output verification in CI.

    liveUrl: z.string().url().optional()
  })
});

export const collections = { projects };

- [ ] **Step 6: Implement content validation**

Create `scripts/verify-content-config.mjs`:

```js
import { access, readFile, readdir } from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const projectDirectory = fileURLToPath(
  new URL('../src/content/projects/', import.meta.url)
);

function parseFrontmatter(source) {
  const match = source.match(/^---\n([\s\S]*?)\n---/);

  if (!match) {
    return {};
  }

  const values = {};
  const lines = match[1].split('\n');
  let currentArray;

  for (const line of lines) {
    if (line.startsWith('  - ') && currentArray) {
      values[currentArray].push(line.slice(4).trim());
      continue;
    }

    const separator = line.indexOf(':');
    if (separator === -1) {
      continue;
    }

    const key = line.slice(0, separator).trim();
    const rawValue = line.slice(separator + 1).trim();

    if (key === 'focus') {
      values[key] = [];
      currentArray = key;
      continue;
    }

    currentArray = undefined;

    if (rawValue === 'true' || rawValue === 'false') {
      values[key] = rawValue === 'true';
    } else {
      values[key] = rawValue;
    }
  }

  return values;
}

export async function validateContent() {
  const errors = [];
  const files = (await readdir(projectDirectory))
    .filter((name) => name.endsWith('.md'))
    .sort();

  const projects = [];

  for (const file of files) {
    const source = await readFile(path.join(projectDirectory, file), 'utf8');
    const project = parseFrontmatter(source);
    projects.push(project);

    for (const field of [
      'title',
      'slug',
      'status',
      'summary',
      'projectType',
      'primaryImage',
      'secondaryImage'
    ]) {
      if (!project[field]) {
        errors.push(`${file}: missing ${field}`);
      }
    }

    if (!Array.isArray(project.focus) || project.focus.length < 3) {
      errors.push(`${file}: focus must contain at least three items`);
    }

    for (const imageField of ['primaryImage', 'secondaryImage']) {
      const image = project[imageField];
      if (typeof image === 'string') {
        const publicPath = new URL(`../public${image}`, import.meta.url);
        try {
          await access(publicPath);
        } catch {
          errors.push(`${file}: ${imageField} does not exist: ${image}`);
        }
      }
    }
  }

  const goodIntentions = projects.find(
    (project) => project.slug === 'good-intentions'
  );

  if (goodIntentions?.status !== 'in-progress') {
    errors.push('good-intentions.md must remain in-progress');
  }

  if (goodIntentions?.liveUrl) {
    errors.push('good-intentions.md must not publish a live URL in the foundation');
  }

  return {
    errors,
    projectCount: projects.length,
    projects
  };
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const result = await validateContent();

  if (result.errors.length > 0) {
    console.error(result.errors.join('\n'));
    process.exitCode = 1;
  } else {
    console.log(`Validated ${result.projectCount} project records.`);
  }
}
```

- [ ] **Step 3: Implement build-output verification**

Create `scripts/verify-build-output.mjs`:

```js
import { access, readFile } from 'node:fs/promises';
import { fileURLToPath } from 'node:url';

const routes = [
  ['/', 'Calypso Digital Studio'],
  ['/services', 'Services | Calypso Digital Studio'],
  ['/work', 'Work | Calypso Digital Studio'],
  ['/about', 'About | Calypso Digital Studio'],
  ['/process', 'Process | Calypso Digital Studio'],
  ['/start', 'Start Your Project | Calypso Digital Studio']
];

const errors = [];

for (const [route, expectedTitle] of routes) {
  const fileName = route === '/'
    ? '../dist/index.html'
    : `../dist${route}/index.html`;

  const file = fileURLToPath(new URL(fileName, import.meta.url));

  try {
    const html = await readFile(file, 'utf8');

    if (!html.includes(`<title>${expectedTitle}</title>`)) {
      errors.push(`${route}: missing expected title`);
    }

    if (!html.includes('name="description"')) {
      errors.push(`${route}: missing meta description`);
    }

    if (!html.includes('id="main-content"')) {
      errors.push(`${route}: missing main-content target`);
    }
  } catch {
    errors.push(`${route}: build output missing`);
  }
}

for (const publicFile of ['favicon.svg', 'site.webmanifest', 'robots.txt']) {
  try {
    await access(fileURLToPath(new URL(`../dist/${publicFile}`, import.meta.url)));
  } catch {
    errors.push(`/${publicFile}: missing from build`);
  }
}

if (errors.length > 0) {
  console.error(errors.join('\n'));
  process.exitCode = 1;
} else {
  console.log(`Verified ${routes.length} routes and public metadata files.`);
}
```
